مشاهده فروشگاه

ورود مدیر فروشگاه

ورود امن با GitHub؛ فقط حسابی که نقش admin در app_metadata دارد اجازه ورود می‌گیرد.

اطلاعات فروشگاه در Supabase ذخیره می‌شود. ورود مدیر با GitHub و نقش امن admin کنترل می‌شود؛ تغییرات این پنل در سایت مشتری همگام می‌شوند.
